# Launch checklist

Tick these before pointing visitors at the new site. Items marked **You** need information or decisions only ViralNest can give.

## Hosting
- [ ] PHP 8.2/8.3, upload limits 10M/12M (DEPLOYMENT-HOSTINGER step 1)
- [ ] `app/` next to `public_html`, contents of `public/` inside it, `.htaccess` copied
- [ ] `app/config.php` created, permission 600, long random `app_key`
- [ ] First administrator created at `/admin/setup`
- [ ] SSL active; Settings > Domain filled and redirect switched on
- [ ] Daily backups on in hPanel; `config.php` saved in the password manager

## Content (You)
- [ ] Contact channels in Settings: WhatsApp, public email, phone, social links (only real ones)
- [ ] Read every page in English and Arabic in Website Content; publish
- [ ] Choose which Arabic pages are ready (Website Content > Structure)
- [ ] Privacy policy reviewed by your legal adviser
- [ ] Service prices: leave hidden, or switch on per service once final
- [ ] Portfolio: send the links/brands; for each case study get **written client permission** before publishing, and add results only with evidence
- [ ] Work with us: confirm the "why work with us" points and steps match how you really work with freelancers

## Email and team
- [ ] SMTP set up and **test email received**
- [ ] Alert recipients for quote requests and for freelancer applications
- [ ] Team accounts with the right roles; everyone changed their one-time password

## Search and analytics
- [ ] Google Search Console verification pasted in Settings, sitemap `https://viralnesteg.com/sitemap.xml` submitted
- [ ] GA4 ID (optional) added; consent banner checked
- [ ] Old WordPress URLs that had traffic redirected if their paths changed

## Final checks
- [ ] Send one test quote request and one test application (with a PDF), check both arrive in Studio and by email, then delete them
- [ ] Check the site on a phone in English and Arabic
- [ ] Delete the old WordPress site only after the new one is confirmed working (keep its backup)
